Overview

ExaltRide is an early-stage car-accessories platform. In three months I worked across its entire ecosystem — from the internal management tools that run the operation to a complete mobile-first redesign of the consumer site.

The problem

The startup needed the "brains of the operation" — an admin dashboard managing complex inventory — while simultaneously needing a consumer site that felt like a native mobile app, without the cost of native development. Two very different design problems, one small team, one deadline.

The approach

Modular, system-first design. I built the B2B infrastructure on a scalable design system, then applied PWA principles to the storefront — bottom-tab navigation, gesture-based interactions, thumb-zone layouts — to simulate a native app feel in the browser.

The three fronts

01

Admin logic

High-density data tables and verification workflows for platform security and oversight — 13+ modules designed for operators who live in this screen all day.

02

Vendor UX

Streamlined the "Add Product" flow with bulk-upload logic and variant management — 8+ panel features that cut listing friction for sellers.

03

Mobile-first storefront

Redesigned the shopping experience around thumb-zone optimization and app-like transitions — a browser experience that behaves like an installed app.

What shipped

  • UX for 13+ admin modules and 8+ vendor-panel features
  • 30+ production-ready screens across Admin, Vendor and User platforms
  • Consumer website redesigned mobile-first for navigation and usability
  • "App-in-browser" UI patterns — bottom tabs, gesture navigation — simulating a native app without native cost
